# slide-forge(赛博风 HTML slides 锻造)

产出物 = **一个自包含 HTML 文件**:浏览器打开即放映(← → 翻页、F 全屏),零外部依赖、离线可用、可直接发给任何人。

## 工作流

1. **先定叙事再动手**:和用户对齐页数(10 分钟 ≈ 12 页)、每页一个主信息、金句(▍前缀 punch 行)。
2. **从模板起**:复制 `assets/template.html`(含全套 CSS 变量、动效引擎、翻页器),在 `<div class="deck">` 里逐页填 `<section class="slide">`。
3. **动效按需取用**(模板已内置):
   - 打字机命令行:`.cmd .typed`(改 `steps(N)` 与 `Nch` 为实际字符数);
   - 数字滚动:任意元素加 `data-count="96067" data-comma="1"`;
   - 逐元素入场:加 `class="rv" style="--d:.3s"`(--d 为延迟);
   - 印章砸落:`.seal`;终端窗:`.term`。
4. **终端实录(可选,炫技件)**:见 `references/asciinema-embed.md`——player JS/CSS 与 `.cast` 录像全部内联进单文件,真文字渲染逐字回放。
5. **质量清单(交付前逐条过)**:
   - [ ] 中文文案全角标点(,。:;?!());代码/命令/英文除外;
   - [ ] ⚠ 若用脚本批量转全角:**HTML 实体(&gt; &lt; &amp;)的分号不可转**,转完必查「&gt;;」类残留;
   - [ ] 每页一个主信息;数字大而重,来源可查;
   - [ ] 1280×720 全屏无溢出、无横向滚动;深色底文字对比度够投影;
   - [ ] 无真名、无凭据、无内部 IP 等敏感信息(对外场合);
   - [ ] 逐页实翻一遍:动效、计数、交互全过。

## 设计 token(模板 `:root` 已定义,整体换肤只改这里)

| 变量 | 值 | 用途 |
|---|---|---|
| `--bg` | `#0a0d12` | 墨夜底 |
| `--ink` | `#ece7da` | 暖纸白正文 |
| `--seal` | `#e8442e` | 朱砂红(强调/印章) |
| `--gold` | `#d9a648` | 鎏金(金句/高亮) |
| `--jade` | `#57c7b8` | 玉青(数据/终端) |
| `--song` | Songti SC 系 | 衬线大标 |
| `--mono` | SF Mono 系 | 数据/命令 |

风格要义:深色终端质感(网格底纹 + 扫描线 + 噪点)、衬线粗黑大标、等宽字体数据、克制的三色点缀。**不要**渐变彩虹、不要圆角卡片堆砌、不要 emoji 当图标。
